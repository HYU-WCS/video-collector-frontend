# 원 요구사항

## 프로젝트

도로 영상 수집·검수 플랫폼. 내부 도구.

- **[원본]** 사용자: 수집가 2명, 검수자 1명
- **[원본]** 내 역할: **프론트엔드**. 백엔드와 DB는 팀원 담당.
- **[원본]** 수집가 앱은 React Native. 검수는 별도 웹.
- **[원본]** MVC 패턴으로 구현. 실제 디렉터리 구조도 MVC로.
- **[원본]** controller에서 API 요청을 보낸다.
- **[확정]** 수집 방식은 **도보**. 차량 아님.
- **[미정]** 촬영물의 최종 용도. 알게 되면 화질·프레임레이트 기준이 달라진다.
- **[미정]** 대상 범위. 성북구 규모로 이야기됐으나 도보 기준으로는 재산정 필요.

## 수집가 워크플로우 [원본]

```
메인 페이지
  → 로그인 (팝업이든 새 페이지든 무관)
  → 촬영: 영상 찍으면서 지도를 얹은 형태. 촬영 버튼 있음.
  → 촬영 중지
  → 메인 페이지
  → 지도 버튼: 전체적으로 내가 어디를 찍었는지 확인 (직전 것만이 아니라 누적)
  → 메인 페이지
  → 앨범: 찍은 것이 리스트로. 왼쪽은 지도로 어디를 찍었는지, 오른쪽은 메타데이터.
```

**[확정] 중지 후 재개 기능은 뺀다.** 인코딩 실패 등으로 영상이 통째로 날아갈 수 있어서
100m 단위로 짧게 끊는 방식을 택했다. 상태는 idle / recording 둘뿐.
