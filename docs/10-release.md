## 2. 공통 준비 체크리스트

1. `cd collector-app && npx tsc --noEmit` — 통과
2. `node tests/roadCache.check.ts` — `all checks passed`
3. 서버 살아 있는지: `curl --cacert certs/dblab-8002-ca.pem https://dblab.166.104.36.71.nip.io:8002/video-collector/api/v1/health`
4. 가짜 데이터 없는지: `grep -rn "mockVideos\|mockProgress" src` → 없음
5. 커밋하고 커밋 해시를 릴리스 노트에 적는다 (빌드는 커밋 안 된 변경도 들어간다 — 커밋 먼저)
6. 버전 올리기 — `app.json`의 `version` (아래 3·4장의 빌드 번호도)
7. 실기기에서 최소 확인: 로그인 → 짧게 촬영 → 정지(멈춤 안내) → 저장 → 앨범에 보임 → 업로드 → 업로드 완료 → 지도 확대해 내 선 보임

## 3. iOS 주의사항

절차는 `09-ios-build.md` A(내 폰), D(원격 수집가 Sideloadly).

- **7일 만료.** 무료 계정이라 설치 7일 뒤 앱이 안 열린다. 수집가에게 만료일을 같이 알린다.
- **`ios/` 폴더는 git에 없다**(`collector-app/.gitignore`). `app.json`을 바꿨으면(버전·권한·플러그인) 빌드 전에 `npx expo prebuild -p ios`. 안 하면 옛 설정으로 빌드된다.
- **빌드 번호:** 지금 `CFBundleVersion` = 1 고정. 사이드로드는 번호가 같아도 덮어 설치되니 급하지 않다.
  버전을 구분하려면 `app.json`에 `ios.buildNumber`를 두고 릴리스마다 올린다 (prebuild 필요).
- **데이터 유지 조건 = 같은 bundle ID로 덮어 설치.** 수집가 폰에서 Sideloadly "Change Bundle ID"를 썼다면
  **매번 같은 값**을 써야 한다. 값이 바뀌면 별개 앱이 되고, 옛 앱을 지우는 순간 안 올린 영상이 사라진다.
- **서버 인증서(CA)** 를 폰마다 설치·신뢰해야 서버와 통신한다 (`09` E). 인증서 만료 2036-10-21.
- Release 빌드만 보낸다. Debug는 Metro(개발 서버)를 찾아서 수집가 폰에서 안 열린다.
- 키체인 암호 = Mac 로그인 암호, "항상 허용". 거부하면 설치가 `ApplicationVerificationFailed`로 실패한다.

## 4. Android 주의사항

```bash
cd collector-app
npx eas-cli build -p android --profile preview      # 끝나면 APK 링크가 나온다
```

- **무료 EAS는 대기열이 있다.** 몇 분~1시간 대기 + 빌드 10~15분. 대기 순번은 알 수 없다.
- **versionCode가 1에서 안 올라간다.** `eas.json`이 `appVersionSource: remote`인데 `preview`에 `autoIncrement`가 없다.
  같은 키로 서명돼 덮어 설치는 되지만, 폰에서 버전 구분이 안 된다 → `preview`에 `"autoIncrement": true` 추가 권장 (미적용).
- **서명 키는 EAS 서버에 있는 것 하나**(Build Credentials `46-lEJDglQ`). 키가 바뀌면 덮어 설치가 안 되고
  지우고 깔아야 해서 안 올린 영상을 잃는다. 키를 지우거나 새로 만들지 않는다.
- **2026-10-30 이전 APK는 서버에 못 붙는다**(옛 http 주소). 수집가가 반드시 새 APK로 바꿔야 한다.
- 서버 CA는 앱 안에 들어 있다(`plugins/withServerCa.js`) — Android 수집가는 인증서를 따로 설치하지 않는다.
- 구글 지도 키는 EAS 환경변수 `GOOGLE_MAPS_ANDROID_KEY`(preview). 빠지면 지도가 회색으로 나온다.
- 설치할 때 "출처를 알 수 없는 앱 설치 허용"이 필요하다 (브라우저나 파일 앱에 허용).

## 5. 수집가에게 같이 보낼 공지

릴리스마다 그대로 붙여 보낸다. 쉬운 말로.

1. **업로드를 다 끝내기 전에 앱을 지우지 마세요.** 안 올린 영상은 폰에만 있어서, 앱을 지우면 같이 사라집니다.
   새 버전은 지우지 말고 **그 위에 그대로 설치**하세요.
2. **한 폰에서는 본인 계정 하나만** 쓰세요 (README 공지, D24).
3. **업로드하는 동안 화면을 끄거나 다른 앱으로 나가지 마세요.** 나가면 멈추고, 앱으로 돌아오면 이어서 올라갑니다.
4. **촬영을 멈추면 그 자리에 서서** 저장이나 폐기를 누르세요. 걸으면 거리가 늘어납니다.
5. 업로드는 **Wi-Fi에서** 하세요. 모바일 데이터면 용량을 묻는 창이 뜹니다 (클립 하나 80~100MB).
6. (iPhone) 앱은 **7일마다 다시 설치**해야 합니다. 서버 인증서를 설치·신뢰하지 않으면 로그인이 안 됩니다.
7. 지도 색: 회색 = 아직 아무도 안 찍음 / 주황 = 검수 대기 / 초록 = 완료 / 빨강 = 반려(누구든 다시 찍으면 됨).

## 6. iPhone 수집가 설치 안내 (그대로 보낼 글)

Android는 APK 링크만 보내면 된다 (설치할 때 "출처를 알 수 없는 앱 허용"만). iPhone은 아래 글을 **IPA 파일·인증서 파일(`dist/dblab-8002-ca.crt`)과 같이** 보낸다.
절차 근거는 `09-ios-build.md` D·E. **Sideloadly는 아직 실제로 해 본 적이 없다** — 첫 설치는 통화하면서 같이 한다.

> **iPhone에 수집 앱 설치하기** (처음 한 번 20~30분, 이후 7일마다 5분)
>
> **준비물**
> - 컴퓨터(Windows 또는 Mac), iPhone 충전 케이블(USB)
> - Apple ID — 본인 것도 되지만 **새로 만든 보조 Apple ID를 추천**합니다 (비공식 설치 프로그램에 입력하기 때문)
> - 제가 보낸 파일 2개: `collector-ios-….ipa`(앱), `dblab-8002-ca.crt`(서버 인증서)
>
> **1. 컴퓨터 준비 (처음 한 번)** — 쓰는 컴퓨터 쪽만 따라 하세요
>
> **Windows (10·11)**
> 1. iTunes·iCloud가 **Microsoft Store에서 깐 것이면 지웁니다** (설정 → 앱 → 설치된 앱 → iTunes / iCloud → 제거). Store 버전으로는 Sideloadly가 iPhone을 못 찾습니다.
> 2. iTunes·iCloud를 다시 설치하고, 다 깔리면 **컴퓨터를 재시동**합니다.
>    [sideloadly.io](https://sideloadly.io/)에서 **Download**를 누르면 나오는 화면에 iTunes·iCloud 설치 링크가 같이 있습니다. 거기서 받으면 됩니다.
>    그 화면에서 못 찾으면 아래 링크로 직접 받으세요.
>    - iTunes: `https://www.apple.com/itunes/download/win64`
>    - iCloud: `https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8CC0-99D41950005E/iCloudSetup.exe`
>    - (iCloud에 로그인할 필요는 없습니다. 깔려 있기만 하면 됩니다)
> 3. [sideloadly.io](https://sideloadly.io/)에서 **Windows용**을 받아 설치합니다.
>    "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**.
> 4. iPhone을 케이블로 연결 → **iTunes를 한 번 열어** iPhone 아이콘이 보이는지 확인합니다.
>    iPhone에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 **신뢰** → 잠금 비밀번호.
>
> **Mac**
> 1. [sideloadly.io](https://sideloadly.io/)에서 **macOS용**을 받아 열고, Sideloadly를 **응용 프로그램** 폴더로 끌어 넣습니다.
> 2. 처음 열 때 "확인되지 않은 개발자"로 막히면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 **그래도 열기**.
>    도우미 설치나 권한을 물으면 허용합니다 (Mac 로그인 비밀번호).
> 3. iPhone을 케이블로 연결 → Mac에 "액세서리 연결을 허용하겠습니까?"가 뜨면 **허용**
>    → iPhone에 "이 컴퓨터를 신뢰하겠습니까?"가 뜨면 **신뢰** → 잠금 비밀번호.
> 4. Finder 왼쪽 목록에 iPhone이 보이면 준비 끝 (iTunes·iCloud는 필요 없습니다).
>
> **2. 앱 설치** (Windows·Mac 같음)
> 1. iPhone을 케이블로 연결한 채 Sideloadly를 엽니다. 위쪽 기기 칸에 내 iPhone 이름이 보여야 합니다.
> 2. `.ipa` 파일을 Sideloadly 창 왼쪽 IPA 아이콘에 끌어다 놓기
> 3. Apple ID 칸에 이메일 입력 → **Start** → Apple ID 비밀번호, 2단계 인증 코드 입력
> 4. 아래에 "Done"이 뜨면 설치 끝 (아직 앱은 안 열립니다 → 3번)
> - "bundle ID" 관련 오류가 나면: Sideloadly **Advanced options → Change Bundle ID**에 `com.본인영문이름.collector`를 넣고 다시 Start.
>   **이 값을 적어 두고 다음부터 항상 똑같이** 쓰세요. 바뀌면 새 앱으로 깔려서 이전 앱의 영상이 섞이거나 사라집니다.
>
> **3. iPhone 설정 (처음 한 번)**
> 1. 설정 → 개인정보 보호 및 보안 → 맨 아래 **개발자 모드 켜기** → 재시동 → 다시 켜지면 "켜기" 확인
> 2. 설정 → 일반 → **VPN 및 기기 관리** → 본인 Apple ID 이메일 → **신뢰**
>
> **4. 서버 인증서 설치 (처음 한 번, 빼먹으면 로그인이 안 됩니다)**
> 1. `dblab-8002-ca.crt`를 **메일 첨부나 AirDrop으로 iPhone에서** 엽니다 (카카오톡으로 열면 설치가 안 될 수 있음) → "프로파일이 다운로드됨"
> 2. 설정 앱 맨 위 **프로파일이 다운로드됨** → 설치 → 비밀번호 → 설치
> 3. 설정 → 일반 → 정보 → 맨 아래 **인증서 신뢰 설정** → `dblab-8002-Local-CA` **켜기** ← 가장 많이 빼먹는 단계
>
> **5. 앱 처음 열기**
> - 카메라·마이크 → **허용**
> - 위치 → **앱을 사용하는 동안 허용**, 그리고 **정확한 위치 켜기** (끄면 거리가 엉망이 됩니다)
> - 받은 계정으로 로그인
>
> **6. 7일마다 다시 설치**
> - 무료 설치라 **7일이 지나면 앱이 안 열립니다.** 지운 게 아니니 영상은 그대로 있습니다.
> - 컴퓨터에 연결해서 2번을 똑같이 다시 하면 됩니다 (Change Bundle ID를 썼다면 같은 값). **앱을 지우지 말고** 그 위에 설치하세요.
> - 자동으로 갱신하려면 (선택): 설치할 때 Sideloadly의 **auto-refresh**를 켜 두고, 아래를 한 번 해 두면
>   컴퓨터가 켜져 있고 iPhone과 같은 Wi-Fi일 때 알아서 다시 설치됩니다.
>   - **Windows:** iTunes → iPhone 아이콘 → 요약 → **"Wi-Fi를 통해 이 iPhone과 동기화"** 체크 → 적용. Sideloadly는 끄지 말고 작업 표시줄에 둡니다.
>   - **Mac:** Finder → iPhone → 일반 → **"Wi-Fi에 연결되어 있을 때 이 iPhone 보기"** 체크 → 적용.
>   - 자동 갱신이 안 됐으면 6일째쯤 케이블로 2번을 직접 하는 게 확실합니다.
>
> **새 버전을 받았을 때:** 업로드를 먼저 다 끝내고(홈의 "업로드 대기" 표시가 없어질 때까지), 2번과 같은 방법으로 새 `.ipa`를 설치하세요. 3·4번은 다시 안 해도 됩니다.
>
> **안 될 때**
> | 증상 | 해결 |
> |---|---|
> | Sideloadly에 iPhone이 안 보임 (Windows) | iTunes·iCloud가 Store 버전인지 확인 → 지우고 링크로 재설치 → 재시동. iPhone 잠금 풀고 "신뢰" |
> | Sideloadly에 iPhone이 안 보임 (Mac) | Finder에 iPhone이 보이는지, "액세서리 허용"·"신뢰"를 눌렀는지. 케이블을 바꿔 보기 |
> | Sideloadly가 안 열림 (Mac) | 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기 |
> | 앱 아이콘을 눌러도 바로 꺼짐 | 7일 만료 → 6번 |
> | "신뢰하지 않는 개발자" | 3-2번 (VPN 및 기기 관리 → 신뢰) |
> | 로그인·회원가입이 계속 실패 | 4-3번 인증서 신뢰가 켜져 있는지 |
> | 지도에 도로가 안 보임 | 로그인 후 1~2분 기다리기 (도로 정보 받는 중) |
