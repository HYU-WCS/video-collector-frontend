## 1. 로그인

**보이는 것**
- 아이디 / 비밀번호 입력, 비밀번호 표시 토글
- 에러 메시지 영역 (불일치, 서버 연결 실패)
- 로딩 인디케이터 (버튼 비활성화 포함)
- 로그인 버튼
- `회원가입` 텍스트 링크 → 1-1

**안 보이는 것**
- **자동 로그인** — 토큰을 `expo-secure-store`에 저장. 현장에서 매번 입력하는 건 고문이다.
- 토큰 만료 시 재로그인 유도
- 입력값 trim
- `KeyboardAvoidingView`

## 1-1. 회원가입 [확정]

팀 요청: "간단하게 하나, 인증 같은 건 없어도 됨". 가입하면 곧바로 로그인 상태로 메인에 간다.

**보이는 것**
- 아이디 / 비밀번호 / 비밀번호 확인
- 에러: 이미 있는 아이디, 비밀번호 불일치, 서버 연결 실패
- `가입하기` 버튼, 로그인으로 돌아가는 링크

**없는 것**
- 이메일·휴대폰 인증, 약관 동의, 비밀번호 규칙 안내

주의: 인증이 없으니 서버 주소를 아는 사람은 누구나 가입된다. 내부 도구라 수용.

## 2. 메인

**보이는 것**
- 인사말 + 누적 거리
- 거리를 **확정 / 검수중**으로 분리 (`확정 8.1km · 검수중 4.3km`). 금액은 표시하지 않는다 (D13)
- `업로드 대기 N건` 배지 → 업로드 큐
- **반려 알림** — `내 영상 2건이 반려됐어요 · 사유: GPS 이상`. 탭하면 앨범(반려 필터)으로 가고
  알림은 사라진다. 한 번 읽으면 다시 뜨지 않는다 (D14). 사유를 보여주는 이유는 같은 실수를 반복하지 않게.
- 지도 / 촬영 타일, 앨범 와이드 타일
- 저장공간 잔량 (임계치 이하일 때만)
- 설정 진입점

**안 보이는 것**
- 앱 진입 시 토큰 검사 → 유효하면 로그인 화면 건너뛰기
- 진척도 캐싱 (오프라인에서도 마지막 값 표시)
- 포그라운드 복귀 시 업로드 큐 자동 처리

## 3. 촬영

**[확정] 가로(landscape) 고정** (2026-09-23, D17). 촬영 화면만 가로, 나머지 화면은 세로.
녹화 버튼은 우측 중앙(오른손 엄지). 회전을 따라가게 두지 않는다 — 클립 화면비가 섞인다.

**보이는 것**
- 거리 위주 표시 (`112m / 100m`), 시간은 보조
- 현재 구간명
- GPS 경고 — **문제 있을 때만**. 정상이면 아무것도 안 보인다.
- 미니맵 (주변 구간 상태 색칠)
- 뒤로가기 (녹화 중엔 확인)

**없는 것**
- 배율 버튼 — 모든 영상의 화각을 통일해 데이터 품질을 일정하게
- 줌/필터/설정 아이콘

**안 보이는 것**
- `useKeepAwake()` — 없으면 걷는 도중 화면이 꺼지며 녹화가 끊긴다
- GPS 1초 수집, 10초마다 임시 파일 백업
- 종료 시 캐시 → 앱 저장소 이동 + 큐 등록
- 저장공간 부족 시 녹화 차단
- 통화·알림으로 백그라운드 진입 시 안전 종료

## 4. 촬영 종료 확인 시트

**저장 / 다시 찍기 / 폐기** 3지선다. 없으면 잘못 찍은 영상까지 전부 업로드되고
검수자가 그걸 다 봐야 한다.

**[제안] 자가 점검 결과를 여기 표시** — `05-decisions.md`의 "촬영 품질 감지" 참조.
```
⚠ GPS 신호가 3번 튀었습니다
⚠ 12초간 바닥을 향했습니다
```

## 5. 지도

줌 레벨마다 다른 것을 보여준다. 상세는 `05-decisions.md`.

- **광역** (z≤13) — 행정동 단위 달성률. 동 이름 + %, 면을 농도로 채움. 도로선 없음.
- **중간** (z14~16) — 도로 구간 단위 색칠
- **근접** (z≥17) — 개별 클립 궤적 + 방향 화살표, 탭 가능

**보이는 것**
- 현재 위치로 이동 버튼
- 필터 칩 (전체 / 내 촬영 / 반려). `내 담당`은 없다 — 구역을 나누지 않는다 (D15)
- 범례 4색
- 진척도 배지
- 로딩 표시 (전체 차단 스피너 아님)

**없는 것**
- 줌 +/- 버튼 (핀치로 충분), 나침반

**안 보이는 것**
- 뷰포트(bbox) 기준 요청, 카메라 이동 디바운스 400ms
- 줌 아웃 시 클립 API 미호출
- SQLite 캐싱 + 증분 갱신
- 화면 밖 폴리라인 렌더링 제외
- 회전·기울기 비활성화 (재계산 비용)

## 6. 지도 — 구간 탭 바텀시트

팝업이 아니라 바텀시트인 이유: 화면 가운데 뜨면 어느 선을 눌렀는지 가려진다.

- 구간명 + 상태 배지
- **반려 사유** — 없으면 똑같이 다시 찍고 또 반려당한다
- 검수 일시
- 반려 구간이면 `누구든 다시 찍으면 됩니다` 안내 한 줄. 특정인의 과제가 아니다 (D14)
- `영상 보기`

## 7. 앨범 리스트

**보이는 것**
- 좌측 썸네일 + 우측 메타 (파일명 / 일시 · 길이 · 거리 / 상태 배지)
- **업로드 상태는 검수 배지와 별개** — 우측 끝에 따로
- `반려 · 재촬영됨`은 회색으로 구분 (다른 사람이 다시 찍어 통과한 경우도 포함)
- 필터 (상태별, 날짜별), 정렬
- 빈 상태 화면
- 로딩 스켈레톤

**안 보이는 것**
- 커서 페이지네이션 (무한스크롤)
- 썸네일 2칸: **궤적 지도**(Android liteMode, 선 색 = 검수 상태) + **첫 프레임**. 둘 다 로컬 파일에서 (D18)
- 썸네일 로컬 캐싱
- `FlatList` 가상화

## 8. 영상 상세

**보이는 것**
- 플레이어 + 스크럽바
- 궤적 지도 (정적, 전체 경로)
- 메타데이터
- 검수 결과 배지 + 반려 사유
- `삭제` (업로드 전일 때만)

**검수 행위는 없다.** 결과를 읽기만 한다.

**[제안] 지도 탭 → 해당 지점부터 재생** — trajectory의 `t` 필드를 쓴다.
다만 클립이 짧아 효용이 작다. 지도 페이지에서 구간 탭 → 그 지점부터 재생하는 쪽이 유용하다.

## 9. 업로드 큐

원본 todo에 없던 화면. **현장에서 LTE가 약하거나 안 터지는 곳이 있어
"찍었는데 아직 안 올라간" 상태가 반드시 생긴다.** 이게 없으면 수집가가 그 사실을 알 방법이 없다.

- 대기/진행/실패 목록, 진행률 바
- 실패 사유 + 재시도
- 전체 재시도 / 전체 취소
- 네트워크 상태, 총 대기 용량

## 10. 권한 요청

시스템 팝업만 띄우면 무심코 거부하고 앱이 아무것도 못 하게 된다.
왜 필요한지 설명하는 화면을 앞에 둔다.

- 카메라 / 위치 / 알림 각각 한 줄 설명
- 위치는 "항상 허용"이 필요할 수 있어 설명이 특히 중요
- 거부 시 설정 앱으로 보내는 버튼
- **안드로이드 10+는 백그라운드 위치가 2단계**, 13+는 알림 권한 별도

## 11. 설정

- 로그아웃
- 자동 업로드 on/off, Wi-Fi 전용 (클립당 100MB면 LTE는 비현실적)
- 영상 화질 (1080p / 720p) — 용량·배터리에 직결
- 저장공간 사용량 + 업로드 완료분 정리
- 앱 버전

## 12. 빈 상태 · 오류

- 빈 앨범
- 오프라인 배너 — 내용을 막지 말 것. 캐시된 건 봐야 한다.
- 지도 로딩 — 전체 차단 스피너 금지

## 전역 (화면 없음)

- 네트워크 끊김 감지 → 오프라인 배너
- API 401 → 자동 로그아웃
- `AppState` 감지 → 복귀 시 갱신
- 에러 바운더리
