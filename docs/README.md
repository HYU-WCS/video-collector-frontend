# docs 인덱스

이 프로젝트의 근거 자료. `CLAUDE.md`는 항상 로드되는 요약이고, 여기는 상세본이다.

| 파일 | 내용 | 언제 읽나 |
|---|---|---|
| `01-brief.md` | 팀에서 받은 원 요구사항 — todo 원문, 워크플로우, 역할 분담 | 범위를 확인할 때 |
| `02-db-schema.md` | 원본 DB 스키마 + 프론트가 요청한 변경 | 백엔드와 합의할 때, 타입 수정할 때 |
| `03-screens.md` | 화면 목록과 화면별 컴포넌트 (보이는 것 / 안 보이는 것) | 화면 구현 들어갈 때 |
| `04-api.md` | API 스펙 (제안) | 통신 코드 짤 때 |
| `05-decisions.md` | 설계 결정과 그 근거 | 기존 결정을 뒤집으려 할 때 **반드시** |
| `06-open-questions.md` | 아직 확정 안 된 것 | 막혔을 때, 팀에 물어볼 것 정리할 때 |
| `07-schema-request.md` | 백엔드 전달용 스키마 변경 요청 (전달용 페이지 링크 포함) | 팀원에게 보낼 때 |
| `08-app-internals.md` | 수집가 앱이 실제로 어떻게 돌아가는지 + 설계 이유 (GPS·거리·업로드·지도), 알려진 문제 | 앱 코드를 이어받거나 리뷰할 때 |
| `09-ios-build.md` | 무료 Apple 계정으로 iOS 빌드·설치하는 방법, 진행 상황, 주의사항 | iOS 빌드할 때 |
| `10-release.md` | iOS·Android 버전 올리기 — 릴리스 노트에 적을 것, 체크리스트, 주의사항, 수집가 공지, 릴리스 기록 | 수집가에게 새 버전을 줄 때 |

## 표기 규칙

- **[원본]** — 팀에서 받은 것. 임의로 바꾸지 말 것.
- **[제안]** — 논의 과정에서 나온 것. 아직 팀 합의 전일 수 있음.
- **[확정]** — 논의를 거쳐 결정된 것. 뒤집으려면 `05-decisions.md`의 근거부터 확인.
- **[미정]** — 결정 안 됨. `06-open-questions.md` 참조.
